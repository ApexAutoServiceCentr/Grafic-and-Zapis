# График смен

Страница для ведения графика смен: циклы 2/2, 3/3, 4/2, 5/2, дежурства, обучения, командировки, отпуска, больничные, отделы и праздничные дни Казахстана.

- `index.html` — вся страница (открывается через GitHub Pages).
- `data.json` — данные графика (сотрудники, настройки, ручные правки). Страница читает и обновляет этот файл через GitHub API.

## Как включить
1. В репозитории: Settings → Pages → Deploy from a branch → ветка `main`, папка `/ (root)`.
2. Страница откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

## Как править график
Просмотр работает без токена. Для правок создайте на GitHub fine-grained токен только на этот репозиторий с правом Contents: Read and write и вставьте его в блок «Синхронизация GitHub» на странице. Токен хранится только в браузере устройства.

Репозиторий и страница публичны: имена сотрудников в `data.json` видны всем, у кого есть адрес.
